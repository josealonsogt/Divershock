# Entrega para Laura

Laura no necesita Visual Studio, Node.js ni el código fuente. Solo necesita la carpeta publicada para su sistema operativo.

## Windows

1. Copiar toda la carpeta publicada al ordenador de Laura.
2. Crear un acceso directo al archivo `Iniciar-Divershocks.bat`.
3. Abrir ese acceso directo. Se abrirá el navegador automáticamente.
4. No cerrar la ventana negra mientras se use la aplicación.

## macOS

1. Copiar toda la carpeta publicada al ordenador de Laura.
2. Abrir `Iniciar-Divershocks.command` con doble clic.
3. Si macOS bloquea el archivo: botón derecho sobre el archivo → **Abrir** → **Abrir**.
4. Se abrirá el navegador automáticamente.
5. No cerrar la ventana de Terminal mientras se use la aplicación.

## Móviles de la tienda

El ordenador debe estar encendido y conectado a la misma WiFi que el móvil.

En el ordenador, consultar su IP local:

- macOS: `ipconfig getifaddr en0`
- Windows: `ipconfig`

Si la IP es, por ejemplo, `192.168.1.45`, abrir desde el móvil:

`http://192.168.1.45:5050`

## Copias de seguridad

Copiar periódicamente el archivo `diverShocks.db` a un pendrive o disco externo. Ese archivo contiene todo el inventario y el historial.
